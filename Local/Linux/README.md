# Running the starter kit on your own Linux machine

These are the guides for a laptop or desktop with Linux (macOS works the same way).
Everything runs on your machine, from your terminal; data and results stay in `data/` and `outputs/` of your clone.

| # | Guide | What you learn |
|---|---|---|
| 1 | [Environment setup](01_environment_setup.md) | venv, `requirements.txt`, CPU vs GPU PyTorch, where the code you will edit lives |
| 2 | [Running Flower](02_running_flower.md) | Simulation (`flwr run`) vs. deployment (SuperLink + SuperNodes in separate terminals), the configuration, seeds and baselines |

Then continue with the tutorials shared by every system: [3. Biased data splits](../../docs/03_biased_data_splits.md), [4. Aggregation strategies](../../docs/04_aggregation_strategies.md), [5. Grad-CAM](../../docs/05_gradcam.md), [6. HAR](../../docs/06_har.md).

Working on the university cluster instead? See [Fep](../../Fep/README.md).
On Windows, see [Wsl](../Wsl/README.md).
