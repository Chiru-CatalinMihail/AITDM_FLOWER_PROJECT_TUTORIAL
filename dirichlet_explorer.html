Dirichlet explorer

See what p ~ Dir(α1, …, αK) looks like. In this repo, dirichlet_split draws one such p per class and gives client k the fraction pk of that class. Tutorial: Biased data splits.

Formulas

α0 = Σi αi
mean = αi / α0
var = αi(α0−αi) / (α02(α0+1))
sd = √var
mode = (αi−1) / (α0−K), if every αj > 1
marginal: xi ~ Beta(αi, α0−αi)
avg. largest share = mean over the N draws of maxi xi

What this means for FL

Read one draw p as how one class is dealt across the K clients: client k gets the fraction pk of that class. dirichlet_split makes a new draw for every class, with the α's set above (αk belongs to client k). The plots below copy the repo's split plots.

Simplification: every class has the same number of samples here, and there is no --min-samples re-draw. The repo re-draws the whole split until each client has at least that many samples.
